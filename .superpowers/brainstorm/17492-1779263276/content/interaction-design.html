B 互动与反馈 · 设计方案

让伙伴对孩子的操作有生动的反馈

1. 点击互动

轻点一下
🐱

✨ 弹跳 + 旋转 + 发光

伙伴"嘭"地跳起来，眼睛闪烁，飘出小心心

连续点击
😵

💫 转晕 + 冒星星

点击太快伙伴会晕，冒星星粒子，很有趣

空闲状态
😴

💤 打哈欠 + 飘忽

15秒不操作自动飘动，偶尔眨眼打哈欠

2. 状态驱动的表情与对话

😢

饱腹度低

💬 "主人我好饿... 能给我点吃的吗?"

表情委屈 · 动作缓慢 · 颜色变灰

😊

心情好

💬 "今天心情好好呀! 一起去答题吧!"

微笑 · 跳跃 · 周围飘小心心

🌟

升级时刻

💬 "我变强了! 谢谢你陪我学习!"

金色光芒 · 旋转变大 · 屏幕震动

3. 喂食互动

喂食流程 (在伙伴详情页)
🍞
拖动食物 →
🐱😋
→ 吃掉！

食物飞向伙伴 → 张开嘴 → 咀嚼动画 → +饱腹度飘出 → 满足表情

技术方案

用 Framer Motion 实现

  • 已有依赖，无需新增包
  • tap/whileHover/AnimatePresence 开箱即用
  • layout animations 做变形效果

注意性能

  • 避免同时太多粒子 (限 20 个)
  • 空闲动画用 CSS animation 而非 JS
  • 手机端降低动画复杂度
