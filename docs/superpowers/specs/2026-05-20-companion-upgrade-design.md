# 伙伴系统升级 — 设计文档（B 互动反馈 + C 进化成长）

## 概述

将静态伙伴卡片升级为有灵魂的养成伙伴：点击有反应、状态驱动表情、喂食有动画、分阶段进化。

## B 互动反馈

### 点击互动
- **轻点伙伴**：弹跳 + 旋转 + 发光 + 飘小心心
- **连续点击**：晕眩表情 + 冒星星粒子
- **空闲 15 秒**：自动飘动 + 偶尔眨眼/打哈欠
- **发言气泡**：根据状态显示不同对话（饿→要吃的、开心→邀答题）

### 状态驱动表情
- **饱腹 < 30**：难过脸 + "主人我好饿..."
- **心情 > 80**：笑脸 + "今天心情好好呀!"
- **升级时刻**：金色光芒 + "我变强了!"
- **连续 7 天打卡**：特殊庆祝对话

### 喂食交互
- 食物图标从物品栏飞向伙伴
- 伙伴张嘴 + 咀嚼动画
- +饱腹度数字飘出
- 满足表情 + 粒子特效

### 技术方案
- 基础阶段用 Lottie (lottie-react)，从 LottieFiles 下载免费动画
- 高级形态用 AI 生成图 + CSS transform 动画
- 粒子特效用 Framer Motion AnimatePresence

## C 进化系统

### 进化阶段（每个伙伴 4 阶段）

| 阶段 | 名称 | 等级 | 美术 | 外观 |
|------|------|------|------|------|
| 1 | 幼年期 | 1-4 | Lottie | 小巧，基础动作 |
| 2 | 成长期 | 5-9 | Lottie | 体型+40%，动作丰富 |
| 3 | 成熟期 | 10-19 | Lottie+特效 | 添加装饰/颜色变化 |
| 4 | 完全体 | 20+ | AI 生成 | 华丽独特外观 |

### 进化链示例

- 小猫：小猫咪 → 大猫 → 猫骑士 → 星辰猫
- 小狗：小狗狗 → 大狗 → 狗将军 → 烈焰犬
- 小恐龙：小恐龙 → 壮恐龙 → 恐龙王 → 雷霆龙
- 小狐狸：小狐狸 → 灵狐 → 九尾狐 → 天狐

### 进化触发
1. 经验值满 → 触发进化检查
2. 全屏特效（金光/花瓣/粒子）
3. 变身动画（变大/变色/变形过渡）
4. 新形态展示 + 奖励积分
5. 记录到数据库 evolution_stage 字段

### 数据库变更
- companions 表新增 `evolution_stage int default 1`

## 实现优先级

1. **P0**: Lottie 安装 + 替换静态 SVG 为 Lottie 动画
2. **P0**: 点击互动 + 空闲动画
3. **P1**: 状态驱动表情和对话气泡
4. **P1**: 进化阶段检测 + 进化庆祝动画
5. **P2**: 喂食动画 + 粒子特效
6. **P2**: AI 生成完全体形态（后续）
